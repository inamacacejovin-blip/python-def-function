# python-def-function

This repository contains a Python activity demonstrating the use of a `def` function.

## Files
- **def_activity.py** — A Python program that defines a function to calculate the area of a rectangle, then calls that function and prints the result.

## What is a def function?
A `def` function lets you group instructions under one name so you can reuse them by calling that name, instead of rewriting the same code repeatedly. Functions can also take inputs (parameters) and return a result.
